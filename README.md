Herd Immunity with Spatial Adaptation Based on Global Prevalence Information
This repository contains the code associated with our paper “Herd Immunity with Spatial Adaptation Based on Global Prevalence Information.”
The code implements epidemic models in which individuals adapt their behavior based on global prevalence information.
Three adaptation-based epidemic models are studied:
AS – Adapted Susceptible model
AI – Adapted Infected model
AIS – Adapted Infected Susceptible model
Adaptation Mechanisms
In addition to the baseline adaptation rules, this repository includes implementations of the following adaptation laws, as discussed in the paper:
Power-law adaptation
Sigmoid adaptation
These adaptation schemes are implemented consistently across all three models (AS, AI, and AIS) and allow systematic comparison of how different functional forms of adaptation influence epidemic dynamics and herd immunity.
Code Contents
For each model (AS, AI, and AIS), the repository provides:
1. Numerical Solutions
2. Fully Mixed Spatial Network Simulations
3. Static Spatial Network Simulations
